# HopperRails

Minecraft 1.21.8 対応のホッパー付きトロッコ制御プラグイン

## 概要

ホッパー付きトロッコがアイテムを吸収・移動する動作を自動的に検出し、レッドストーン信号を制御するプラグインです。

## 機能

- **待機モード**: ホッパー付きトロッコがチェストの下で待機している状態
- **吸収モード**: ホッパー付きトロッコがチェストからアイテムを吸収している状態
- **移動モード**: アイテムの吸収が完了し、トロッコの下のレールにレッドストーン信号を送信

## ビルド方法

```bash
./gradlew build
```

ビルドされたjarファイルは `build/libs/HopperRails-0.0.1.jar` に生成されます。

## インストール

1. プラグインをビルドするか、リリースページからダウンロード
2. `HopperRails-0.0.1.jar` をサーバーの `plugins` フォルダにコピー
3. サーバーを再起動

## 設定

`plugins/HopperRails/config.yml` で以下の設定が可能です：

```yaml
# デバッグモード（詳細なログを出力）
デバッグモード: false

# レッドストーン信号の持続時間（ティック）
レッドストーン信号持続時間: 20

# アイテム吸収チェック間隔（ティック）
チェック間隔: 10
```

## 使用方法

1. ホッパー付きトロッコをレールの上に配置
2. トロッコの上にチェストを配置
3. チェストにアイテムを入れる
4. トロッコが自動的にアイテムを吸収
5. 吸収完了後、トロッコの下のレールにレッドストーン信号が送信される

## 動作の仕組み

1. ホッパー付きトロッコがチェストの下にいる場合、**待機モード**
2. アイテムの吸収を開始すると、**吸収モード**に移行
3. アイテムの吸収が完了すると、**移動モード**に移行し、レールの下のブロックを一時的にレッドストーンブロックに変更してレッドストーン信号を送信
4. トロッコが再びチェストの下に戻ると、**待機モード**に戻る

## 必要環境

- Minecraft 1.21.8
- Spigot / Paper サーバー
- Java 17 以上
